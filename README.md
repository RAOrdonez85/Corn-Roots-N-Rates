# Corn Roots by N Rate

An interactive teaching model of corn root development under three nitrogen rates (N0, N150, N300), built from real root data measured in the field over three seasons (2017, 2018 and 2019).

**Open the interactive page:** use the website link in the *About* section of this repository.

## What students can explore

- Root growth from planting to day 140 in a 75 cm row width, 0–180 cm deep
- Root length density in each soil layer (0–15, 15–30, 30–60 … 150–180 cm)
- Roots from neighboring rows meeting between rows by day 40
- Maximum rooting depth at R2: 155 cm (N0), 160 cm (N150), 168 cm (N300)
- Crown and brace roots, stalk and leaves through the season
- Root mass over the season for the three seasons combined

## Use on any device

Runs in any modern web browser on computers, tablets and smartphones. No installation or account needed.
